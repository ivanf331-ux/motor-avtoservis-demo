# МОТОР — демонстрационный сайт автосервиса

Учебный макет одностраничного сайта для автосервиса в Лесном (Свердловская область). Это **демонстрационный проект**, не сайт существующего автосервиса. Контакты и некоторые тексты — заглушки.

## Публикация на GitHub Pages

1. В GitHub создайте новый **Public** репозиторий `motor-avtoservis-demo` с веткой `main`.
2. Нажмите **Add file → Upload files** и перетащите файлы `index.html`, `settings.js`, `.nojekyll`, `README.md`, а также папку `images` из этого комплекта. Проверьте, что `index.html` расположен в **корне** репозитория, а изображение — в `images/foto_iz_pervogo_varianta.webp`.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** укажите `Deploy from a branch`, ветка `main`, папка `/ (root)` и **Save**.
5. Через несколько минут проверьте предполагаемый адрес: `https://ivanf331-ux.github.io/motor-avtoservis-demo/` (он работает только **после** включения GitHub Pages и завершения публикации).

## Как редактировать

В файле `settings.js` меняются название, город, описание, телефон, адрес, часы, услуги и преимущества. Пока `demoMode: true`, кнопка звонка не набирает вымышленный номер.

Не используйте демо-контакты как настоящие. Перед продажей клиентского сайта подтвердите услуги и обещания с владельцем и согласуйте хостинг.
